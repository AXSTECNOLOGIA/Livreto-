# ORIMI — Amigos da Fauna Brasileira (workspace de produção)

> Fonte de verdade das aprovações: **ORIMI_REGISTRO_MESTRE_APROVACOES.md** (Google Drive, pasta "ORIMI - Fichas dos Personagens").
> Este repositório guarda roteiros, storyboards, scripts e relatórios. Artes oficiais aprovadas **permanecem no Drive** e não são substituídas aqui.

## Estrutura
```
ORIMI/
├── referencias/          # cópias de referência recebidas no chat (não substituem as oficiais do Drive)
├── personagens/          # fichas técnicas de ANIMAÇÃO (derivadas das fichas aprovadas)
├── livros/volume_01/     # índice do Volume 01 (arquivos no Drive)
└── animacoes/episodio_01_pingo/
    ├── roteiro/  storyboard/  imagens/  videos/  audio/  legendas/
    ├── projetos/         # scripts (recortes, animatic, montagem FFmpeg)
    ├── entregas/pt_BR/  entregas/en_US/
    └── relatorios/       # diagnóstico, pendências, validações
```
